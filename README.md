# Pesquisa de Satisfação de Atendimento - TudoWeb

## Descrição da atividade
A empresa de marketing **TudoWeb** deseja realizar uma pesquisa de opinião com seus clientes para identificar o grau de satisfação em relação ao atendimento prestado.
O programa foi desenvolvido em **Python** e realiza a coleta de informações de **50 entrevistados**.

Para cada participante, são solicitados:
- Nome;
- Idade;
- Opinião sobre o atendimento.

As opções disponíveis para avaliação são:
1. EXCELENTE
2. BOM
3. RUIM

Ao término da pesquisa, o programa informa:
- A quantidade de respostas **EXCELENTE**;
- A quantidade de respostas **RUIM**.

---

### Objetivo
O objetivo desta atividade é praticar conceitos fundamentais da programação em Python, principalmente:
- Entrada de dados;
- Variáveis;
- Estruturas de repetição;
- Estruturas de decisão;
- Operadores de comparação;
- Contadores;
- Exibição de resultados.

---

#### Tecnologias utilizadas
- Python
- Entrada de dados com `input()`
- Estrutura de repetição `for`
- Estruturas condicionais `if`, `elif` e `else`
